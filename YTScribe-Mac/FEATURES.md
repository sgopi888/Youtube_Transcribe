# YTScribe: Features

YTScribe is a native macOS app (SwiftUI, Apple Silicon) with three jobs:

1. Summarize YouTube videos.
2. Download their audio as MP3.
3. Strip the vocals from any song to make a karaoke instrumental.

Everything except the summary (OpenAI) and the YouTube fetches runs on this Mac.

The UI follows the **Liquid Graphite** design in `stitch_ytscribe_macos_suite/`.

---

## 1. Window and navigation

| Area | What it shows | What it does |
|---|---|---|
| **Top bar** (52 pt) | Traffic lights, app icon, "YTScribe" | The window's own title bar is hidden, and this bar replaces it. |
| Center tabs | **AI Summary · Audio Downloader · Karaoke AI** as a segmented control with a sliding pill | Switches the workspace. Also closes Audio Vault. |
| Status pill | Glowing cyan dot, CPU icon, "N jobs running" or "On-device engine ready" | Live count of summaries, downloads and separations in progress. |
| Folder link | `~/Music/YTScribe/` | Opens that folder in Finder. |
| Gear and profile circle | Settings icons | Both open **Settings**: the OpenAI key and the model name. |
| **Sidebar** (240 pt) | "TRANSCRIPTIONS" label, plus **Recent Captions, Downloads Queue, Stem Separation, Audio Vault** | The first three match the three tabs. Audio Vault opens History in the main area. The active item is highlighted. |
| Active Jobs card | "N of M" in cyan, with a progress bar | How many of this session's jobs are finished. |
| Paste anywhere | ⌘V in the window | Starts jobs for every YouTube link in the pasted text. On AI Summary that means a summary, on Audio Downloader a download. Karaoke AI ignores links. |
| Drop anywhere | Drag audio files onto the window | A dashed indigo outline appears. On **Karaoke AI**, each file starts separating at once. On the other tabs, it is added to the Audio Downloader list. |

Minimum window size is 1180 × 760. The app is always in dark mode.

## 2. AI Summary tab

### Clipboard banner
- Shows when the clipboard holds a YouTube link that isn't queued yet. It checks when the tab opens, when the app becomes active, and when the job list changes.
- Displays: "Detected YouTube link from clipboard:" followed by the link in monospace.
- **Ignore** hides it for that link.
- **Add to Queue** starts the job but keeps your current selection.
- **Auto-Extract** starts the job and opens it.

### Queue YouTube Summaries card
- Header tags:
  - `OpenAI · <model>`
  - "No audio download required" in cyan
  - "N in queue"
- A multi-line URL field. Any text containing a link starts jobs **immediately**, and the field clears. Paste one link or many, separated by lines or commas.
- Two hint chips: "⌘V anywhere" and "Several links at once".
- A "Technical deep-dive" style tag.
- **Batch Ingest ⏎** (⌘⏎) submits what is in the field.

### Job cards (one per video, newest on top, all running in parallel)
- **Thumbnail:** the YouTube thumbnail (`i.ytimg.com`), with a **LIVE**, **COMPLETED** or **FAILED** badge.
- **Title** and status pill: Fetching transcript → Summarizing *i/n* → Complete, or Failed.
- **Teaser:** the first plain line of the summary, or `youtu.be/<id>` until the summary exists.
- **Chips:** the model, plus a `youtu.be/<id>` link that opens the video. On the right, a word count in cyan.
- **While running:**
  - A status line with a spinning icon and an "*i / n* Chunks" counter.
  - A primary-to-cyan progress bar. It is indeterminate while the transcript is being fetched.
  - A **Transcript stream** box with the word count and the opening lines.
- **Finished:**
  - The save folder path.
  - `Model:` and `Format: Markdown` tags.
  - **Copy .md**, **Reveal in Finder** and **View Summary**.
- **Failed:** the error text in red, plus **Retry**.
- The selected card gets a cyan-to-indigo line along its top edge. Click a card to select it.

### Stats row
- **Library Storage:** real size of `~/Downloads/YTScribe`.
- **Summaries Saved:** count from Audio Vault.
- **Summary Model:** the model set in Settings.

### Document inspector (right, 420 pt)
- **Header:**
  - The file or folder name.
  - A **Rendered / Raw .md / Transcript** switch.
  - **Copy** puts the current view on the clipboard.
  - **Show summary.md in Finder.**
- **Body:**
  - "GENERATED BY YTSCRIBE • MODEL: …" in cyan monospace.
  - A large title.
  - `youtu.be/<id> • N transcript words`.
  - The summary rendered from Markdown: headings, bullets, numbered items and code blocks.
- **Footer:** "Saved to disk" or "Not saved yet", plus "Encoding: UTF-8 • N chars".

### How summaries work
- **Transcript:** fetched through YouTube's InnerTube caption API. Manual captions are preferred, then auto-generated ones.
- **Summary:** OpenAI (default model `gpt-6-luna`, changeable in Settings) writes a detailed technical summary.
  - Long transcripts are split into chunks.
  - Each chunk is summarized, then the parts are merged into one summary.
- **Saved to** `~/Downloads/YTScribe/<title> [<id>]/`, with `summary.md` and `transcript.txt`, and added to Audio Vault.

## 3. Audio Downloader tab

### Link bar
- A URL field. Any pasted link starts a download right away; Return also submits.
- A **Clipboard** chip downloads the link that is on the clipboard. A **⌘V** hint chip sits beside it.
- **Enqueue Batch** submits what is in the field.
- The upload icon adds audio files from your Mac.
- **Audio Profile:** MP3 VBR V0 (best quality).
- ✓ Embed Metadata, plus a "Parallel downloads" label.

### Target Vault card
- **Target Vault:** `~/Music/YTScribe/Originals/`.
- **Karaoke tracks:** `~/Music/YTScribe/Karaoke/`.
- **Reveal in Finder** and **Karaoke Folder** open those folders.

### Active Pipeline
- Header: "ACTIVE PIPELINE", an "N items" tag, and live "Downloading: x • Ready: y" counts.
- **Each card shows:**
  - The YouTube thumbnail, or a gradient tile for local files, with a "V0" badge.
  - The title and status pill.
  - The source (YouTube or Local file), the link or file name, and the file size.
- **Downloading:** a large percentage, a progress bar, and the line "Downloading the best audio stream and converting to MP3…".
- **Done:**
  - **Play Preview** or **Pause**.
  - **Open in Finder.**
  - A **⋯** menu with "Open in default app", "Save As…" and "Remove vocals…".
  - A "Stored:" path and the karaoke status chip.
- **Selected and done:** an inline **Karaoke** panel with:
  - A model picker.
  - **Generate Karaoke** (or **Run Again** once a result exists).
  - A progress bar.
  - When finished: **Play**, **Save As…** and **Show in Finder**, and the result can be dragged out.
- **Failed:** the error text, plus **Retry**.

### Stats row
- **Codec Engine:** yt-dlp + ffmpeg, MP3 VBR V0.
- **Vault Capacity:** real bytes used under `~/Music/YTScribe`, the file count, and free disk space, with a bar.
- **Karaoke Library:** the instrumental count, the latest track, the originals count, and whether the Roformer engine is installed.

### Now-playing bar (floats at the bottom while audio plays)
- Track name and format.
- Controls: back 10 s, a large play/pause button, forward 10 s, and stop.
- **Stem Split** sends the track to Karaoke AI and starts separating it.
- A **real waveform** of the file, decoded on the Mac. Click it to seek. Elapsed and remaining time sit on either side.

### How downloads work
- yt-dlp (bundled) downloads the best audio stream, and ffmpeg converts it to MP3 at quality 0 with metadata.
- Several downloads run at once.
- Files land in `~/Music/YTScribe/Originals/` and appear in Audio Vault.

## 4. Karaoke AI tab

### Top strip
- "Local Separation · Core ML · PyTorch MPS".
- "0 Cloud Uploads • 100% Offline Processing".
- **Output Directory** `~/Music/YTScribe/Karaoke/`. Click it to open the folder.

### Audio Stem Ingest (drop zone)
- "AUDIO STEM INGEST • Ready" and a **⌘O** hint.
- A waveform icon and "Drop MP3, WAV, or FLAC here".
- **Choose from ~/Music/YTScribe/** opens the file picker in Originals.
- **Browse Finder…** (⌘O) opens it anywhere.
- Format chips: MP3, WAV, FLAC, M4A/AAC, AIFF/OGG. "Batch Multi-Drop Supported".
- **Accepted formats:** mp3, m4a, wav, flac, aac, ogg, opus, aiff.
- **Files from elsewhere** are copied into Originals first. Your original file is never touched.

### Separation Model Engine
Click a row to choose the model for new files.

| Model | Badge | Notes |
|---|---|---|
| **HTDemucs v4 (Core ML)** | FAST | Bundled Core ML model, no setup, starts instantly. Needs macOS 26 or later. |
| **BS-Roformer Viperx 1297** | BEST QUALITY | Higher quality, slower. Runs in a private Python environment on PyTorch MPS. The first use sets that environment up once and needs internet. |

### Separation Objective
- **Instrumental Mode** (active): removes all vocals and outputs a clean backing track as MP3.
- **Karaoke Mode** (greyed out, "Not available yet"): would keep the backing vocals and remove only the lead.

### Stem workspace (the selected file)
- **Header:**
  - The file name and format tag.
  - The model and a live status chip.
  - **Play** (the original).
  - **Run again** with the currently chosen model.
  - **Show original in Finder.**
- **Master Input (Full Mix) lane:** the real waveform of the original, with a playhead and click to seek, plus a time readout while it plays.
- **Instrumental lane:**
  - Status text and a **PLAY/PAUSE** chip.
  - The real waveform of the result, with click to seek.
  - While working: a progress bar, "Setting up the Roformer engine…", or the error.
- **Instant Destination:** the output path. Once the file exists, a button reveals it.
- **Show Original**, **Show Instrumental** and **Export Instrumental MP3** (Save As). The workspace can be dragged out as the result file.

### Separation Queue
- Header: "N Jobs Pending" and **Clear Finished**.
- **Each row shows:**
  - A state icon: spinning, waiting, done or failed.
  - The file name, plus "model • Instrumental Mode".
  - A progress bar with %, "Setting up…", "Completed • Instrumental MP3 saved", or the error.
  - **Show Finder** or **Retry.**
- Click a row to load it into the stem workspace.
- **Output:** `~/Music/YTScribe/Karaoke/<song> (karaoke).mp3`, or `(karaoke, roformer).mp3` for the Roformer model. It is added to Audio Vault.

## 5. Audio Vault (History)

- **Opening it:** the sidebar's **Audio Vault** item. It fills the main area.
- **Tabs:** **Summaries · Originals · Karaoke.**
- **Open folder:** a button opens the folder for the current tab and shows how many items it holds.
- **Rows:**
  - A play/pause button for audio, or a document icon for summaries.
  - The title.
  - The subfolder and date added.
  - A trash button.
  - When a track is playing, a seek slider appears under its row.
- **Opening a summary** loads it, with its transcript, back into the AI Summary tab.
- **Reordering:** drag rows. The order is saved.
- **Removing:** asks first.
  - **Remove from history** keeps the file.
  - **Move file to Trash** is only offered for files inside `~/Music/YTScribe`, or a summary's folder in `~/Downloads/YTScribe`. Songs you added from elsewhere are never trashed.
- **Right-click menu:** Show in Finder, Remove….
- **Always in sync with the folders:** new files show up, deleted files drop out, and a missing file is shown in red as "File missing". It re-syncs each time the app becomes active.

## 6. Settings

| Setting | Notes |
|---|---|
| OpenAI API key | Saved in `~/Library/Application Support/YTScribe/openai.key` with user-only (0600) permissions. Not in the Keychain, because the ad-hoc signed app would ask for Keychain permission again after every rebuild. |

## 7. Design system (Liquid Graphite)

| Token | Value | Used for |
|---|---|---|
| Surface / lowest / low / high / highest | `#0F131C` `#0A0E17` `#181B25` `#262A34` `#31353F` | Canvas, top bar, cards, buttons, active pill |
| Primary | `#C0C1FF` on `#1000A9` text | Primary buttons, profile circle, playhead tint |
| Secondary | `#D0BCFF` / `#571BC1` | Generative and karaoke badges |
| Tertiary | `#4CD7F6` | Status dots, progress, timestamps, success |
| Error | `#FFB4AB` | Failures |
| Text | `#DFE2EF` / variant `#C7C4D7` | Body text and secondary text |

The shared components are all in `Sources/YTScribe/Theme.swift`:

- **Segmented control:** the glass control with a sliding pill (`GlassSegmented`).
- **Buttons:** primary, glass, ghost and icon styles.
- **Badges and chips:** the status `Pill`, the monospace `Tag` chip and `StatusDot`.
- **Progress:** `ProgressBar`, determinate or indeterminate.
- **Thumbnails:** the YouTube thumbnail tile (`Thumb`).
- **Cards:** the `.card()` surface.

Waveforms are in `Waveform.swift`. They are peak bars decoded with AVFoundation off the main thread and cached per file.

Type: the system font (SF Pro) for interface text, and SF Mono for paths, timestamps and metadata.

## 9. Build and install

```bash
./build_app.sh                 # builds build/YTScribe.app (ad-hoc signed, this Mac only)
swift test                     # core tests
./Icon/build_icns.sh           # only after changing Icon/source.png: rebuilds Icon/AppIcon.icns
```

Install or update in Applications. This quits the running app, replaces the old copy, refreshes the Dock icon cache and relaunches:

```bash
osascript -e 'quit app "YTScribe"'; rm -rf /Applications/YTScribe.app && cp -R ~/Desktop/Apps/Youtube_Transcribe/YTScribe-Mac/build/YTScribe.app /Applications/ && touch /Applications/YTScribe.app && killall Dock && open /Applications/YTScribe.app;
```

If Finder still shows the old icon, run `killall Finder`.
