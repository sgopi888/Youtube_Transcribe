lightbulb Core Executive Thesis

The transformer architecture operates on purely autoregressive token prediction. Starting from simple bigram probability matrices to modern scaled dot-product multi-head attention with layer normalization and residual pathways, language modeling fundamentally comes down to projecting discrete tokens into continuous latent vectors and progressively attending to historical context.

1. Essential Architectural Stages

  • Character-level Tokenizer: Minimal vocabulary of 65 unique characters enables transparent inspection of tensor shapes (B, T, C) without the complexity of byte-pair encoding.
  • Scaled Dot-Product Attention: Attention scores calculated via Q @ K.T / sqrt(d_k). Division by variance prevents soft-max collapse into saturated regions.
  • Causal Masking (Tril): Applying lower-triangular matrix zeroing ensures past tokens cannot glean information from future indices during autoregressive self-supervised generation.

class Head(nn.Module):
    """ one head of self-attention """
    def __init__(self, head_size):
        super().__init__()
        self.key = nn.Linear(n_embd, head_size, bias=False)
        self.query = nn.Linear(n_embd, head_size, bias=False)
        self.value = nn.Linear(n_embd, head_size, bias=False)
        self.register_buffer('tril', torch.tril(torch.ones(block_size, block_size)))

    def forward(self, x):
        B, T, C = x.shape
        k = self.key(x)   # (B, T, head_size)
        q = self.query(x) # (B, T, head_size)
        wei = q @ k.transpose(-2, -1) * k.shape[-1]**-0.5
        wei = wei.masked_fill(self.tril[:T, :T] == 0, float('-inf'))
        wei = F.softmax(wei, dim=-1)
        v = self.value(x)
        return wei @ v
